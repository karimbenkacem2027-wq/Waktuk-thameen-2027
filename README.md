# وقتك ثمين V3 | Your Time Is Precious

نسخة تطوير شاملة مبنية على مشروع HTML + Capacitor الأصلي، مع الحفاظ على صفحات V2 وإضافة أنظمة الإنتاجية الجديدة.

## ما الذي يتضمنه V3؟

- هوية بصرية جديدة باللون الأخضر الداكن والذهبي، مع إزالة شارة العلم من الواجهة.
- تحسين البطاقات والأزرار والتنقل والتجاوب مع شاشات الهاتف.
- صفحة مصحف داخل التطبيق: اختيار السورة، عرض النص بالرسم العثماني، وتشغيل تلاوة مشاري العفاسي عبر AlQuran Cloud API.
- صفحة أذكار صباح ومساء مع عدادات محلية، وإظهار مصادر مختصرة والتنبيه إلى النصوص المختصرة.
- تصحيح رقم واتساب إلى 0778388778.
- إضافة manifest وService Worker كملفات ثابتة بدلاً من Blob URL، مع تخزين واجهة التطبيق الأساسية مؤقتاً.
- تحسين أيقونة التطبيق وإعدادات Capacitor.
- إزالة إذن QUERY_ALL_PACKAGES من إعداد Android لتجنب طلب صلاحية واسعة غير لازمة لمراقبة UsageStats.
- جميع ميزات V2: القرآن والتلاوة، الأذكار، مؤقت الاستغفار، الأنشطة، الأهداف، الإحصاءات، التذكيرات ومراقبة الاستخدام.
- Daily Challenges: تحديات يومية مع تسجيل الإنجاز محلياً.
- Habits Tracker: متابعة العادات اليومية مع تنبيه واضح أن السجل لا يقيس قيمة العبادة.
- Deep Focus: جلسات تركيز بمؤقت محفوظ محلياً وسجل للجلسات المكتملة.
- Weekly Analytics وLife Progress: تقارير من البيانات المتاحة فعلياً، مع تصدير CSV.
- App Limits: حدود استخدام مع تنبيهات عند بلوغ الحد. هذه النسخة لا تحظر التطبيقات فعلياً.
- AI Assistant: واجهة مساعد متصلة اختيارياً بـ Firebase Callable Cloud Function، مع تحليل محلي توضيحي عند عدم إعداد الخادم.
- تحديث هوية الإصدار إلى V3 مع استمرار دعم العربية والإنجليزية.

## متطلبات البناء

- Node.js 20
- Java 17
- Android SDK / Android Studio عند البناء محلياً
- Python 3 + Pillow لتوليد أيقونات Android

## بناء نسخة Android عبر GitHub Actions

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من تبويب Actions شغّل workflow المسمى **Build Android APK**.
3. بعد اكتمال البناء، حمّل artifact المسمى `waqtak-v3-debug-apk`.

## البناء محلياً

```bash
npm install
npx cap add android
python make_icons.py
python patch_app.py
python setup_native.py
npx cap sync android
cd android
./gradlew assembleDebug
```

ملف APK التجريبي يظهر في:
`android/app/build/outputs/apk/debug/app-debug.apk`

## إعداد مساعد الذكاء الاصطناعي

1. أكمل إعداد Firebase Web في `admin/firebase-config.js`.
2. من Firebase Authentication فعّل Anonymous sign-in.
3. ثبّت Firebase CLI ثم سجّل الدخول.
4. من جذر المشروع نفّذ: `firebase functions:secrets:set OPENAI_API_KEY` وأدخل المفتاح عند الطلب. لا تضع المفتاح في ملفات الواجهة أو GitHub.
5. نفّذ `cd firebase/functions && npm install` ثم ارجع إلى جذر المشروع.
6. انشر الوظيفة: `firebase deploy --only functions:waqtakAIAdvisor`.
7. تأكد من ربط المشروع الصحيح في `.firebaserc` أو نفّذ `firebase use --add`.

المساعد يرسل السؤال ومؤشرات استخدام مجمعة فقط إلى Cloud Function. لا تحفظ الوظيفة نص السؤال أو سجل المحادثة. يوجد حد أولي قدره 20 طلباً لكل مستخدم مجهول يومياً.

## حدود النسخة الحالية

- التحديات والعادات يتم تأكيد إنجازها يدوياً؛ لا تدّعي أنها تحققت آلياً.
- حدود التطبيقات ترسل تنبيهاً عند تجاوز الوقت، ولا تمنع تشغيل التطبيق الآخر.
- Focus Mode مؤقت داخل التطبيق، ولا يضمن منع المقاطعات أو إبقاء واجهة المؤقت مرئية عند إغلاق التطبيق.
- بيانات Life Progress والتقارير تعتمد على السجلات الموجودة فقط، ولا تنشئ بيانات تاريخية مفقودة.
- لم يتم تنفيذ بناء APK أو اختبار فعلي على جهاز Android ضمن هذه الحزمة؛ يلزم تشغيل GitHub Actions واختبارها على الهاتف.

## ملاحظات مهمة قبل النشر

- ميزة مراقبة التطبيقات الأخرى على Android تحتاج إلى منح المستخدم إذن **Usage Access** يدوياً من إعدادات النظام. لا يمكن للتطبيق تفعيل هذا الإذن نيابةً عنه.
- الإشعارات الخلفية تعتمد على قيود Android والشركة المصنعة وإعدادات البطارية. يجب اختبارها على الهاتف المستهدف، خصوصاً مع تفعيل توفير البطارية.
- قراءة القرآن والتلاوة داخل التطبيق تحتاج إلى الإنترنت عند جلب السورة لأول مرة. مصدر البيانات ظاهر داخل صفحة المصحف. يُستحسن مراجعة النص على مصحف موثوق قبل الاعتماد عليه في الحفظ.
- صفحة الأذكار تعرض بعض الصيغ مختصرة عمداً بعلامة الحذف، ولا ينبغي اعتبارها نصاً كاملاً للحفظ. يجب استكمال مراجعة النصوص والمراجع قبل النشر العام.
- هذه حزمة مصدر مطوّرة وليست APK نهائياً موقعاً. يلزم بناء Android واختباره على أجهزة فعلية، ثم إعداد مفتاح توقيع إصدار Release للنشر على Google Play.
